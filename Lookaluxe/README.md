# LOOKALUXE
https://docs.google.com/presentation/d/1bqSrmohiYjbngBFSs0AEO6w4tT4m48nyUtjN-rC_MDs/edit?usp=sharing

This app allows you to upload luxury items and find cheap alternatives! 
To run, donwload and navigate to the lookaluxe-backend folder, then run python app.py. 
Currently, the AI model struggles to recognize some items so I reccomend testing the app out with simple images like sunglasses.
